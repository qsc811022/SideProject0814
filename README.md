# 升學路徑圖

台灣國中、高中現行升學制度的純靜態資訊網站，使用 HTML、CSS 與 JavaScript 製作，可直接部署到 GitHub Pages。

## GitHub Pages 部署

1. 將專案推送到 GitHub repository。
2. 進入 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. Branch 選擇 `main`、資料夾選擇 `/ (root)`，按下 **Save**。

網站內容為制度導讀，實際規則、名額與時程均應以當年度官方招生簡章為準。
